# Skill growth policy

Do not create a new skill merely to organize generic advice or repeat a rule
already handled by `AGENTS.md`, the main workflow or an existing reference.

Create a skill only when all of these are true:

- the request has a distinct trigger and should not activate for nearby tasks;
- it requires specialized decisions, tools or safety boundaries;
- the current workflow and skills cannot express the behavior without harmful
  duplication or ambiguity;
- at least one evaluation case can verify the new behavior;
- the skill can remain concise through progressive disclosure.

Before creating it, try the smallest change to an existing skill or reference.
After creating it, add an evaluation case and observe it in a real task before
adding more rules.
