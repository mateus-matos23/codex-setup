# Final report

Read this reference only at the end of a task.

Before reporting completion:

- inspect the final diff, including untracked files;
- run focused and relevant static checks plus `git diff --check`;
- distinguish product failures from environment or pre-existing failures;
- report changed behavior, validation performed, remaining risks and assumptions.

Do not claim completion when a concrete validation failure is unclassified.
If a broader check could not run, state the reason and its impact instead of
silently treating the task as fully validated.
